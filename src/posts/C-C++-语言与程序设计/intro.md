## 为什么要写这套教程

如果你曾经尝试自学 `C` 语言，大概率见过这样的开场：

```c
#include<stdio.h>

int main() {
    return 0;
}
```

然后教程会告诉你：`#include` 是包含头文件，`int main()` 是主函数，`return 0` 表示正常结束。

你可以把这段代码背下来，甚至能照着模板写出不少程序。但很长一段时间里，你都会处于一种“我知道要这么写，但不知道为什么要这么写”的状态。这种一知半解的感觉，显然是不合理的。

所以在这套教程里，我们不急着讲语法，而是先从最底层开始，看看一段程序到底是怎么被计算机执行的，高级语言又是为了解决什么问题才被发明出来的。理解了这些，代码就不再是死记硬背的咒语。

## 教学大纲

整体会分为六个阶段：

1. **基础语法与逻辑控制**：变量、输入输出、运算符、分支、循环
2. **模块化与连续内存**：函数、数组、字符串
3. **底层基石与复合数据**：指针、动态内存、结构体
4. **基础数据结构**：链表、栈、队列、Trie、并查集
5. **基础算法**：排序、查找、递归、DFS、BFS
6. **面向对象**：类、继承、多态

前五个阶段主要使用 `C` 语言，只在必要时顺带提及 `C++` 的写法；第六阶段正式进入 `C++` 的面向对象部分，而在 `C` 语言讲解的过程中，我们也会提到面向对象的相关思想，因为它在 `C` 语言当中也非常好用。
